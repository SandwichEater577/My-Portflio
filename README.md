# My Portfolio

My personal developer portfolio, displayed as a modern [Bento Box](https://en.wikipedia.org/wiki/Bento).

## Live Demo

Check out the live site here: **[vercel.app](https://my-portflio-git-main-sandwicheater577s-projects.vercel.app/)**

## Tech Stack

- **Framework:** React (via Vite)
- **Styling:** CSS Grid, Flexbox
- **Deployment:** Vercel
- **Design:** Anime/Manga inspired Bento layout

## Running Locally

If you want to run this project on your own machine:

1. Clone the repo: `git clone https://github.com/SandwichEater577/My-Portflio.git`
2. Navigate into the folder: `cd My-Portflio`
3. Install dependencies: `npm install`
4. Start the dev server: `npm run dev`
